# BGM 탭 연동 및 서식 융화 구현 계획

## 1. 개요
BGM 블록에 소속 탭 속성을 부여하고, 사용자가 좌측 탭 뱃지를 클릭하여 탭을 변경하거나 '자동(직후/직전 블록 따름)'으로 설정할 수 있도록 합니다. 메인/잡담 탭에서는 기존 플로팅 필(Pill) 스타일을 유지하되, 비밀탭 및 정보탭에서는 같은 탭의 대사와 하나의 탭 박스로 자연스럽게 연속 묶이고 테마 색상이 융화되도록 미리보기와 HTML 내보내기를 모두 개선합니다.

---

## 2. 세부 구현 내용

### 2.1 BGM 탭 자동 결정 및 변경 로직
1. **기본 탭 규칙 (Auto)**
   - BGM 블록의 소속 탭이 지정되지 않았거나 `'auto'`인 경우:
     - **직후 블록**의 `tabId`를 우선 상속합니다.
     - 맨 마지막 블록인 경우 **직전 블록**의 `tabId`를 상속합니다.
   - 데이터 구조: `log.tabOverride` (기본값 `'auto'`) 또는 `log.tabId`에 반영.
2. **좌측 탭 뱃지 UI & 탭 변경 드롭다운**
   - BGM 블록의 좌측 상단/헤더 영역에 일반 로그 및 삽화와 동일한 형태의 **탭 뱃지**를 표시합니다.
   - 탭 뱃지 클릭 시 드롭다운(또는 SearchableSelect/팝오버)을 열어 `자동 (직후/직전 블록 따름)` 및 등록된 각 탭을 선택할 수 있도록 구현합니다.
   - 탭 변경 시 `onBatchUpdateLog`를 통해 실시간으로 상태를 갱신합니다.

### 2.2 미리보기 (`LogItem.tsx`) 렌더링 개선
1. **메인 / 잡담 (일반) 탭**
   - 기존의 단독 플로팅 필(BgmItem) 디자인을 그대로 유지합니다.
2. **비밀탭 (`secret`) / 정보탭 (`info`)**
   - **연속 묶음(Container Merge)**:
     - 동일 탭의 이전/다음 대사 블록과 연결될 경우 `mergeWithPrev` 및 `mergeWithNext` 규칙을 적용하여 한 탭 박스 안에 끊김 없이 이어집니다.
     - 상/하단 라운딩 및 마진이 연속 블록 규칙에 맞춰 자동 정렬됩니다.
     - 섹션 시작 부분이고 '탭 이름 표시' 옵션이 켜져 있을 경우 탭 이름 헤더를 동일하게 출력합니다.
   - **스타일 융화**:
     - 탭의 배경색(`getSecretBg(tabColor)` / 정보탭 배경) 및 좌측 보더(`borderLeft: 4px solid ...`)를 컨테이너에 적용합니다.
     - BGM 카드 및 재생 버튼, 아이콘, 볼륨/시간 표시의 테두리 및 액센트 색상이 해당 탭의 테마 컬러와 어울리도록 조화롭게 스타일링합니다.

### 2.3 HTML 내보내기 (`htmlGenerator.ts`) 개선
1. **BGM 탭 해석 로직 동기화**
   - `originalLogs` 전처리 단계에서 BGM 블록의 `tabId`를 `tabOverride` 및 자동 규칙(직후/직전 블록 탐색)으로 정확하게 해석합니다.
2. **비밀탭/정보탭 그룹화 및 CSS 융화**
   - BGM 블록이 비밀/정보 탭일 경우 기존 탭 그룹 청크(Chunk)에 포함되어 동일한 탭 컨테이너 박스 안에 렌더링되도록 처리합니다.
   - 내보낸 HTML 내에서도 BGM 버튼의 보더/액센트가 탭 컬러(`tabColor`)를 반영하도록 CSS를 확장합니다.

## 3. 검증 계획
1. **탭 자동 상속 동작 검증**:
   - 비밀탭 대사 바로 앞에 BGM 추가 시 비밀탭 스타일 자동 적용 확인.
   - 마지막 위치에 BGM 추가 시 직전 대사 탭 자동 상속 확인.
2. **탭 변경 UI 검증**:
   - 좌측 탭 뱃지 클릭을 통해 수동으로 메인 ↔ 잡담 ↔ 비밀 ↔ 정보 탭으로 변경할 때 즉각 반영되는지 확인.
3. **디자인 및 연속 묶음 검증**:
   - 비밀/정보 탭 내에서 BGM 위/아래에 동일 탭 대사가 있을 때 하나의 박스로 깔끔하게 연결되는지 확인.
   - 메인/잡담 탭에서는 기존 플로팅 디자인이 손상 없이 유지되는지 확인.
4. **HTML 내보내기 검증**:
   - 내보낸 HTML 파일에서 비밀탭/정보탭 BGM이 에디터와 동일하게 탭 박스 안에 올바르게 렌더링되는지 확인.
5. **빌드 및 린트 검증**:
   - `compile_applet` 및 `lint_applet`을 수행하여 무결성 확인.
